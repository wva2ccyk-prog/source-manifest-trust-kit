# Expected Operator Interpretation

This scenario should help an operator separate four things:

- Supported observation: the official notice supports that a shuttle pilot is scheduled and describes route/time details.
- Review-needed context: the news article supports that objections and possible route revisions were reported, but does not prove the cause of the route decision.
- Weak/rumor claim: the forum source alleges private-group pressure without primary evidence, so the operator should verify meeting records, disclosures, or named sources before repeating it.
- Do-not-repeat finance wording: the market commentary contains action/probability/return language that should be masked or treated as unsafe to conclude.

Useful next step:

- Use the verification packet to seek primary records for the route-change causality claim.
- Do not repeat the forum causality claim as fact.
- Do not repeat or act on finance-sensitive recommendation wording.
